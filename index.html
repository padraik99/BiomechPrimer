Use it on every device

Install it like an app

Edge (desktop and Surface): open the site, then menu (…) → Apps → Install this site as an app.

Android (Chrome): menu (⋮) → Add to Home screen or Install app.

iPhone (Safari): Share → Add to Home Screen.

Sync progress

Each device keeps its own progress. Export to your Google Drive folder when you finish a session, and import on the next device before you start. Import merges: the newest copy of every answer and tick wins.
